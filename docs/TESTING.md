# Тестування — класичний волейбол (зала)

## 1. Автотести

```bash
npm install      # один раз: jsdom для тестів інтерфейсу
npm test         # ~210 тестів, ~15 с
```

| Набір | Що перевіряє |
|---|---|
| `tests/match.test.js` | правила: сети, баланс, вирішальний, тайм-аути, заміни (6 на сет), картки (червона = очко й подача суперникові), скасування, протокол, CSV |
| `tests/markup.test.js` | звʼязки файлів: id, порядок скриптів, офлайн-кеш, деплой, шрифти, маніфест |
| `tests/ui.test.js` | тапи на пульті в jsdom: очки, подача, тайм-аути, заміни/картки, налаштування, палітри |
| `tests/display.test.js` | табло: синхронізація з пультом, банери, тайм-аут, фінал, звуки (фальшивий Web Audio) |
| `tests/mini.test.js` | міні-пульт: кнопки, синхронізація з пультом в обидва боки, пересилання на сервер |
| `tests/live.test.js` | міні-табло `live.html` і «Посилання на матч»: другий суддя, синхронізація |
| `tests/server.test.js` | сервер на справжніх сокетах: кімнати, ключ судді, доказ власності, ліміти, перевірка стану, `error`/`bye` |
| `tests/archive.test.js` | архів матчів: підсумок, оновлення без дублів, ліміт і брак місця; у пульті — матч закінчився → в архіві → протокол, CSV, видалення |
| `tests/i18n.test.js` | англійська версія: словник, фрази з числами, вибір мови, повнота перекладу статичного тексту всіх сторінок |
| `tests/link.test.js` | `link.js` без браузера: збереження посилання, адреса другого судді, відлік без звʼязку, причини збою |
| `tests/helpers/site.js` | не тест: де лежать файли (`public/…`, `server/…`) — тести звертаються до них короткими іменами |
| `tests/pages.test.js` | GitHub Pages: вибір сервера (`config.js`), `scripts/pages-config.js`, workflow, відносні адреси |
| `tests/flow.test.js` | **повний матч 3:2** через інтерфейс пульта з підключеним табло — від першої подачі до протоколу |

Пропущених і відкладених тестів немає (пляжний волейбол доведено).

### e2e: справжній браузер, кілька пристроїв

```bash
npx playwright install chromium   # один раз
npm run e2e                       # ~15 с
```

`tests/e2e/sync.spec.js` піднімає справжній сервер і відкриває кожен «пристрій» в окремому
контексті Chromium (своє сховище, як різні телефони):

| Сценарій | Що перевіряє |
|---|---|
| глядач бачить рахунок наживо | пульт → посилання → `live.html` у глядача, очки й скасування |
| другий суддя | пульт судді за посиланням, очки в обидва боки, ключ зникає з адресного рядка |
| перезапуск сервера посеред матчу | самозванець займає кімнату — пульт із доказом повертає її, табло відновлює рахунок |
| чужий ключ | зрозуміле пояснення «Ключ судді не підходить», без нескінченних спроб |
| глядач закрив табло | кімната звільняється одразу (`bye`) |
| обидва судді без звʼязку | сервер лежить, кожен суддя додав своє очко — після звʼязку в обох 1:1 |
| без пінг-понгу | після злиття за 3 с жоден пульт не надсилає стан |
| скасування без звʼязку | скасоване на одному пульті не воскресає, очко другого лишається |
| новий ключ судді | старий суддя відключений з поясненням, новий рахує, глядачі не помітили |
| англійська (`i18n.spec.js`) | перемикач мови в налаштуваннях; повний матч англійською на пульті, великому табло, міні-пульті й міні-табло — без українського тексту; `?lang=en` на табло глядача |
| пляжний матч (`beach.spec.js`) | пресет «Пляж», зміна сторін кнопкою кожні 7 очок (у вирішальному — 5), технічний тайм-аут на 21 з відліком на великому табло, раз на сет, фінал 2:1 |
| архів матчів (`archive.spec.js`) | матч закінчився → в архіві з рахунком → протокол «з архіву» → переживає перезавантаження → видалення; пошук за командою й турніром, лічильник, «нічого не знайдено» |

У GitHub Actions e2e — окрема задача `e2e` у `deploy.yml`; при падінні туди ж вкладаються трейси Playwright.

## 2. Ручна перевірка (те, чого не видно в автотестах)

Запуск: `npm start` → http://localhost:3000 (або адреса на Render).

### Телефон (портрет і альбом)
- [ ] Тап по половині — очко; великі зони, влучаєш не дивлячись
- [ ] Вібрація на очко, окрема — на кінець сету
- [ ] Екран не гасне під час матчу
- [ ] «Додати на головний екран» → відкривається без рядка браузера
- [ ] Довге натискання на іконку → ярлики «Табло» і «Смуга»
- [ ] Режим польоту → застосунок і табло відкриваються, рахунок на місці

### Ноутбук + проєктор (другий екран)
- [ ] Меню → «Табло для глядачів → на другий екран» → браузер питає дозвіл → вікно відкривається на проєкторі
- [ ] Подвійний клік на табло → повний екран; курсор зникає за 3 с
- [ ] Клік на табло → підказка «звук вимкнено» зникає; свисток на тайм-аут чути
- [ ] Сигнал на кінець сету й матчу; галочка «Звуки на табло» в налаштуваннях їх вимикає
- [ ] Банери: заміна, жовта, червона (очко суперникові), «Сет виграла…»
- [ ] Вирішальний сет: на 8 очках «зміна сторін» на обох екранах → «Поміняти сторони» → команди їдуть на інші половини і там, і там
- [ ] Фінал: «… виграла · 3:2 · 25–23 …» — рахунок з боку переможця

### Міні-табло з керуванням
- [ ] Пульт: меню → «Міні-табло з керуванням» → маленьке окреме вікно
- [ ] +1 / −1 у міні-пульті → одразу на основному пульті й великому табло
- [ ] Очко на основному пульті → одразу в міні-пульті
- [ ] Тайм-аут у міні-пульті → відлік на основному пульті; «Завершити» там → зникає й тут
- [ ] «Подача ⇄» до першого розіграшу сету, далі кнопка неактивна
- [ ] На телефоні: mini.html в окремій вкладці — кнопки великі, без прокрутки вбік
- [ ] «Міні-табло окремо» в меню пульта → лише табло у своєму вікні, внизу «Керування ↗»
- [ ] «Керування ↗» → сторінка лише з кнопками й рахунком у картках; очки → одразу на окремому табло
- [ ] «Показати табло» / «Сховати табло» у міні-пульті; після перезавантаження вибір зберігся

### Посилання на матч (після деплою на Render)
- [ ] Пульт: меню → «Посилання на матч» → «Створити посилання» → два посилання, «на звʼязку»
- [ ] Міні-табло на іншому телефоні (мобільний інтернет, не той Wi-Fi) → назви, сети, очки
- [ ] Пульт для другого судді на третьому телефоні → одразу той самий рахунок
- [ ] Очко, тайм-аут, заміна, картка з другого пульта → видно на першому й на міні-табло
- [ ] ⟲ на будь-якому пульті скасовує останню дію в матчі
- [ ] Вимкнути Wi-Fi на пульті на 30 с, набрати 2 очки → увімкнути → обидва очки дійшли
- [ ] Перезавантажити будь-який пульт → у тому ж матчі, посилання не змінились
- [ ] «Закрити посилання» → міні-табло й другий пульт перестають оновлюватись

### Протокол
- [ ] «Завантажити CSV» → файл «протокол-<турнір>-<команди>.csv» відкривається в Excel кирилицею
      (у тестовому Linux-браузері кирилична назва падала на «download» — перевірити на Windows)
- [ ] Заміни й картки в протоколі й у CSV

### Повний сценарій матчу (15 хв)
1. Налаштування: назва турніру, команди, «Зал».
2. Меню → «Хто подає першим» → друга команда.
3. Сет 1: тайм-аут на 10:10, заміна 7→12, жовта №4 суперникові, 25:23.
4. Сет 2: помилкове очко → ⟲ → ⟳ → ⟲; червона №9 → очко суперникові; 20:25.
5. Сет 3: баланс 26:28. Сет 4: 25:15.
6. Сет 5: на 8:5 поміняти сторони, 15:13.
7. Фінал → «Скасувати очко» → гра повертається на обох екранах → знову очко.
8. Перезавантажити пульт → той самий фінал. Протокол → CSV.
